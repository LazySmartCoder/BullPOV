# 📈 BullPOV

**A skill-based stock prediction platform where users forecast market movement and compete for pooled rewards.**

---

## 🚀 Overview

BullPOV is a game-of-skill platform built around stock market predictions.  
Users participate by predicting whether a stock will go **up or down the next day**, based on their own analysis.

The platform creates a **competitive prediction environment**, where users stake an entry amount, and the total pool is distributed among those who predict correctly.

This project was designed to combine **finance, decision-making, and real-time engagement** into a single interactive system.

---

## ❓ Problem Statement

Most stock market platforms focus only on:
- Passive investing  
- Data visualization  
- Learning tools  

They do not actively engage users in **decision-making or skill validation**.

Bullpov addresses this by:
- Turning predictions into a **skill-based competitive system**  
- Allowing users to **test their market understanding in real scenarios**  

---

## 💡 Solution

A platform where:

- Users analyze stock trends  
- Predict whether a stock will **rise or fall the next day**  
- Enter prediction pools with a stake  
- Winners receive distributed rewards from the total pool  

---

## ✨ Key Features

- 📊 Stock movement prediction (Up / Down)  
- 💰 Pool-based reward distribution system  
- ⚖️ Skill-based outcome logic  
- 🔗 Payment integration using Cashfree APIs  
- ⚡ Real-time interaction support (WebRTC)  
- 👥 Scaled to handle 200+ users  

---

## ⚙️ How It Works

### 🧠 Conceptual Flow

1. User selects a stock  
2. User predicts:
   - 📈 Bull (price will rise)  
   - 📉 Bear (price will fall)  
3. User enters the pool with a stake  
4. After market outcome:
   - Correct predictions win  
   - Pool money is distributed among winners  
   - Losing stake is redistributed  

---

### 🛠️ Technical Flow

- Frontend handles:
  - User input and prediction interface

- Backend manages:
  - Prediction logic  
  - Pool distribution system  
  - Payment processing  

- Integrated Services:
